# Getting help

**English** · [Português](SUPPORT.pt-BR.md)

cratedeck is a community project maintained in spare time. There is no paid
support and no response-time guarantee, but questions are welcome.

## Where to ask

- **How do I…? / Is this expected?** Open a thread in
  [Discussions → Q&A](https://github.com/glaucolauria/cratedeck/discussions).
- **An idea or a missing feature:** Discussions → Ideas, or a feature
  request issue when it is concrete.
- **Something is broken:** a bug report issue, with the cratedeck and
  CrateDB versions and the steps to reproduce.
- **A security problem:** privately, as [SECURITY.md](SECURITY.md) says.
  Never in a public thread.
- **CrateDB itself** (SQL, clustering, performance): the
  [CrateDB documentation](https://cratedb.com/docs) and its community
  forum. cratedeck is not part of CrateDB and is not supported by Crate.io.

English or Portuguese, as you prefer.

## Before you post

- Search open and closed issues and discussions.
- Remove credentials, hostnames and real data from anything you paste.
